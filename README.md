# GalChat

将 QQ 私聊转化为实时的旮旯给木！！！

**作者：Shinochanwww** · Windows x64 · 闭源软件 · **0.5.20**

[下载安装包](https://github.com/xiaomi0530/GalChat/releases/latest) · [快速开始](docs/QUICKSTART.md) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/xiaomi0530/GalChat/issues)

**QQ：当前可用。微信：待开发，当前版本不提供微信连接、同步或发送功能。**

## 能做什么

- 手动选择 QQ 好友独立私聊，连接后自动同步文字与 Emoji。
- 将双方消息分别呈现为角色台词，支持履历、手写回复和暂不回复。
- 使用自己的 DeepSeek API Key 生成回复选项，并根据聊天内容驱动表情、动作和好感度。现实聊天也有选项可以选！
- 四位女性、四位男性角色可选；每位好友的角色、背景、关系、好感度和草稿分别保存。
- 点击选项直接发送；编辑时 Enter 发送，Ctrl+Enter 换行。
- 朋友、同学、同事、暧昧、恋人、自定义各有完整的默认说话习惯；可以编辑，或恢复当前关系的默认内容。

## 下载与使用

1. 在 [0.5.20 发布页](https://github.com/xiaomi0530/GalChat/releases/tag/v0.5.20) 下载 `GalChat-Setup-0.5.20-x64.exe`。
2. 退出旧版 GalChat / 花间信，运行安装程序。已有数据继续沿用。
3. 按入门教程创建联系人，在 QQ 原版主窗口双击好友打开独立私聊，再回到设置连接；需要 AI 生成回复选项时保存自己的 DeepSeek Key。

安装使用无需 Node.js 或 Python。新用户默认 QQ、晴栀、慢速文字、显示好感度。界面内置中文字体，运行时无需另行下载。完整步骤见[快速开始](docs/QUICKSTART.md)。

## 当前版本范围

当前仅支持 QQNT 好友独立私聊的文字与 Emoji，不支持群聊、图片理解或语音转写。QQ 独立私聊可被遮挡，请勿最小化；同步不代表完整历史。

**微信支持属于待开发功能，尚未在本版开放。** 旧微信记录继续保留在本机，界面中隐藏，不会合并至 QQ；暂不承诺开放时间。

570 项核心回归、56 项界面回归及安装包完整性检查通过。这些是隔离测试，本次没有新增实机收发或真实模型效果验收。安装包未签名，支持范围见[兼容性说明](docs/COMPATIBILITY.md)。

保存 DeepSeek Key 后开启云端分析及回复生成，可在设置中关闭。消息由用户点选或按 Enter 触发发送。聊天数据库保存在本机且未加密；AI 数据处理见[隐私说明](docs/PRIVACY.md)。
