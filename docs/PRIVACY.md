# 隐私说明

适用版本：GalChat 0.5.7 · 更新：2026-10-17 · 作者：Shinochanwww

## 本地记录

联系人、双方消息、草稿、好感度、角色背景、分析结果和发送核查记录保存在本机。微信与 QQ 以及不同联系人的记录分别保存，不自动合并。

聊天数据库**没有应用层加密**。API Key 使用 Windows 本地保护机制加密保存，不写入聊天导出文件。系统保护不能防御拥有同一用户权限的恶意软件。

应用保留本地数据库恢复快照；卸载默认保留数据。删除联系人只处理应用内相应记录，不撤回已经发到聊天客户端或服务商的数据。自行导出的文件和另存备份需自行管理。

## 连接微信 / QQ

用户主动连接后，应用通过 Windows 界面控件读取目标私聊的文字、方向、标题和窗口信息。不使用官方消息推送接口，不解密客户端数据库，不索取登录凭据，也不自动遍历通讯录。

微信部分方向判断会在本机内存读取已绑定窗口的图像，可能包含该窗口的聊天、头像与侧栏；不截取整个桌面、不落盘、不提交给 DeepSeek。QQ 正文来自控件文本，不使用 OCR。

连接可能在已绑定窗口内进行有限补读与滚动。发送使用官方客户端，可能需要短暂调整绑定窗口的位置与输入焦点，再恢复；这些能力受客户端版本和窗口状态影响。不能将“后台适配”理解为任何环境下都不会影响操作。

点击回复选项或手写回复按 Enter 会尝试发送一次，不再要求第二次确认；Ctrl+Enter 换行，输入法选字不发送。结果未知时不会自动重发，需要用户核查。

## DeepSeek

初次启动不启用 AI。**保存 DeepSeek API Key 会自动开启 AI、云端处理和回复生成**，保存按钮旁有说明；可在设置中关闭。自动生成只生成候选，发送仍由用户点选或 Enter 触发。

启用后，当前联系人的所选聊天上下文、关系与语气设置、消息标识、时间间隔和相关好感度信息会提交到 DeepSeek API，用于判断是否说完、生成回复、表情动作及好感度变化。默认上下文上限为 20 条，可在设置中修改。其他联系人记录、角色图片、微信窗口截图及整个本地数据库不随该请求提交。

请求直达 `https://api.deepseek.com`，不经 GalChat 自建中转服务。费用计入用户自己的 API 账户，DeepSeek 对请求数据的处理以该账户适用的服务条款为准。本应用不承诺服务商零保留或不用于训练。

关闭 AI、撤销云端处理或移除 Key 后停止新的分析请求；取消请求不能撤回已提交给服务商的数据。停用 AI 后仍可在兼容环境中同步和手写回复。

## 下载与反馈

本发布仓库和安装包不包含开发者的聊天记录、API Key 或测试联系人资料。GitHub 下载及 Issue 由 GitHub 提供。反馈入口：[GalChat Issues](https://github.com/xiaomi0530/GalChat/issues)。公开反馈前请遮挡聊天内容、昵称、账号和密钥；不要上传数据库或 Key 文件。
