# GalChat 0.5.20 支持范围

Windows x64；原版 QQNT 好友独立私聊；文字与 Emoji。不支持群聊、图片理解、语音转写。

在 QQ 原版主窗口双击好友打开独立私聊，再手动选择该窗口。独立私聊可被遮挡，不能最小化；只有当前客户端可提供的消息能够同步，不能承诺完整历史。

点击选项直接发送一次；结果未知不自动重发。“已发送”仅表示本地可靠回显，不代表对方已读。

本次改动进行后台隔离测试和安装包检查，没有新增 QQ 实机收发验收。各电脑、QQ 版本和窗口状态仍需实际使用验证。微信接口及画面读取组件已停用，不在本版安装包中。

微信支持：待开发，当前版本仅支持 QQ。
