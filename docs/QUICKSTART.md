# GalChat 0.5.20 使用说明

1. 设置 → 会话：输入 QQ 好友备注，点击创建。
2. 在 QQ 原版主窗口双击好友，打开独立私聊。回到设置 → 连接，手动选择该窗口并连接。独立私聊可被遮挡，请勿最小化。
3. 显示“自动同步中”后，新消息自动进入 GalChat。
4. 设置 → 回复：保存 DeepSeek API Key 后开启自动生成选项。点击选项直接发送一次；自己输入时 Enter 发送、Ctrl+Enter 换行。“暂不回复”跳过本轮。

H 查看履历，Space 推进台词。角色、背景、关系、好感度和草稿按联系人分别保存。

设置 → 关系：朋友、同学、同事、暧昧、恋人和自定义各有一套默认说话习惯，保存后用于生成回复。切换关系会替换未修改的默认内容；自己编辑过的内容会保留。点击“使用默认说话习惯”可重新填入当前关系的默认内容，再点保存。

本版只支持 QQ。微信功能暂时停用，旧联系人和聊天记录仍保留在原本机数据库，不转入 QQ。升级保留原有设置和密钥。

微信支持：待开发，当前版本仅支持 QQ。
