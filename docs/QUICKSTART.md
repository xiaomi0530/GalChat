# GalChat 0.5.21 · 三步开始聊天

[下载安装包](https://github.com/xiaomi0530/GalChat/releases/latest) · [返回首页](../README.md)

下载 `.exe`，退出旧版后安装。当前支持 QQ；**微信待开发，尚未开放**。下面的截图使用虚构联系人和聊天示例。

## 1. 连接 QQ

1. 在 **QQ 原版主窗口**（带消息列表）双击好友，打开该好友的**独立私聊窗口**，停留在最新消息。
2. GalChat **设置 → 会话**：输入好友备注，点击 **创建**。
3. **设置 → 连接 → 手动选择独立私聊**：选中该好友窗口，再点 **连接所选窗口**。
4. 显示 **自动同步中** 后，新消息会自动进入 GalChat，无需反复点击同步。

![手动选择好友独立私聊窗口并连接](../images/galchat-0.5.21-qq-connect.png)

QQ 独立私聊可以被遮挡，**不要最小化**。列表没有窗口时，先确认已打开独立私聊，再点“手动选择独立私聊”刷新。回复会发送到你选中的窗口。

## 2. 生成回复

**设置 → 回复**：填入自己的 **DeepSeek API Key** 并点 **保存**。这会开启云端分析和自动生成回复。

![DeepSeek API Key 设置位置及 AI 开关](../images/galchat-0.5.21-ai.png)

返回主界面，收到新消息后，软件判断对方说完再生成选项；点击 **回复** 查看。也可以在回复面板点 **生成回复** 主动生成。

AI 使用当前会话的所选聊天上下文，费用由你的 DeepSeek API 账户承担。若没有生成选项，检查密钥是否已保存、AI 开关是否开启，以及 **设置 → 连接** 中的 **自动生成回复** 是否开启。

## 3. 选择并发送

**点击一条选项就会直接发送，无需再点发送按钮。**

![回复选项、自己输入和暂不回复的位置](../images/galchat-0.5.21-replies.png)

- 自己写：点 **自己输入**，输入后按 **Enter** 发送；**Ctrl + Enter** 换行。
- 不想回复：点 **暂不回复**。
- 查看历史：按 **H** 或点 **履历**；按 **Space** 推进台词。

“已发送”表示本地客户端已出现发送回显，不代表对方已读。

## 按好友定制

在设置中选择 **角色、背景、关系**，各联系人分别保存。六种关系有不同的默认说话习惯；切换关系会更新未修改的默认内容，手写内容会保留。点 **使用默认说话习惯** 可重置编辑框，再点 **保存** 生效。
