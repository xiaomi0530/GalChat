# 快速开始

## 连接好友

1. 打开“设置 → 会话”，选择 QQ 或微信，创建联系人。
2. 在原版 QQ / 微信主窗口双击好友会话，打开**独立私聊窗口**。保持该窗口打开、不要最小化。
3. 在 GalChat 的“设置 → 连接”中完成连接：
   - **QQ：**点“手动选择独立私聊”，选中好友窗口，再点“连接所选窗口”。
   - **微信：**确保原版主窗口选中同一好友，勾选已核对联系人，再点“连接”；也可使用手动选择入口。

连接后会持续读取当前可读取的内容，无需反复手动同步。若提示暂停，按显示的具体原因处理。手动选窗会把该窗口绑定到当前联系人，请先确认没有选错人。

## 回复

- “设置 → 回复”保存自己的 DeepSeek API Key，会开启 AI、云端处理和自动生成回复。费用计入你的 DeepSeek API 账户。
- **点击选项：**直接尝试发送该条回复。
- **自己输入：**Enter 发送，Ctrl+Enter 换行；输入法选字不会发送。
- **暂不回复：**跳过这一轮。
- **发送结果未知：**先到原聊天客户端核对，再选择已发出或未发出；不要为了确认结果重复点击发送。

不使用 AI 也可同步、阅读、手写回复。连接可用性取决于客户端环境；本测试版的范围见[兼容性说明](COMPATIBILITY.md)。

## 外观与记录

- “角色”“背景”“关系”按当前联系人分别保存，微信和 QQ 同名联系人也不会合并。
- “显示”可修改自己的昵称和文字速度。
- H 打开履历，R 打开回复，Space 推进文字，Esc 返回或打开设置。
- “关于”查看隐私、版本、作者和导出入口。

## 升级

退出旧版后运行新安装包。GalChat 延用花间信的数据目录，不需重新建立联系人。卸载默认保留应用数据；自己导出的文件需自行管理。不要将聊天库、API Key 或未打码聊天截图上传到公开 Issue。
